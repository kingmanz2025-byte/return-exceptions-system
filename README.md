# نظام إدارة استثناءات المرتجعات — نموذج أولي لأندرويد

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية متجاوبة قابلة للتثبيت كتطبيق ويب على أندرويد (PWA) بعد استضافتها على HTTPS.
- 57 فرعًا تجريبيًا، لكل فرع حصة أساسية 3.
- إنشاء طلبات الاستثناء، مراجعتها واعتمادها أو رفضها في وضع إدارة الكاشير.
- تحويل الحصص وتسجيل حركة التحويل.
- لوحة مؤشرات وتصدير تقارير CSV متوافقة مع Excel.
- سجل تدقيق محلي.
- حفظ البيانات على نفس الجهاز/المتصفح عبر localStorage.

## مهم قبل الاستخدام الفعلي
هذه نسخة MVP تجريبية وليست نظامًا متعدد المستخدمين متصلًا بخادم. تبديل الدور داخل التطبيق لغرض التجربة فقط وليس حماية صلاحيات حقيقية. البيانات لا تتزامن بين أجهزة الفروع، ولا تستخدم بيانات عملاء حقيقية. يلزم قبل الإطلاق:
1. خادم API وقاعدة بيانات مركزية (مثل PostgreSQL).
2. تسجيل دخول حقيقي، حساب منفصل لكل فرع، وصلاحيات على الخادم.
3. معاملات ذرية لمنع صرف الرصيد مرتين، ومراجعة تحويلات الرصيد.
4. تخزين آمن للمرفقات، نسخ احتياطي، وسجل تدقيق غير قابل للتعديل من المستخدم.
5. مراجعة أمنية واختبار على بيانات تجريبية.

## التشغيل للتجربة
يمكن فتح `index.html` محليًا للتجربة الأساسية، لكن تثبيت PWA يحتاج استضافة HTTPS أو بيئة localhost. ارفع الملفات إلى استضافة ثابتة تدعم HTTPS، ثم افتح الرابط من Chrome على أندرويد واختر **إضافة إلى الشاشة الرئيسية**.

## سياسة الرصيد
- الحصة الأساسية: 3 استثناءات لكل فرع شهريًا.
- لا يُخصم رصيد الطلب المعلق؛ يُخصم عند الاعتماد فقط.
- الموافقة فوق الحصة تُطلب منها مبررات صريحة.
- الحصص المنقولة تسجل في سجل التحويلات.
